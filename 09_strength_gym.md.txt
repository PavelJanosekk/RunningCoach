# Silový trénink / hybrid

## Filozofie: hybrid ≠ BB + běh

| | Čistý BB | Čistý běžec | **Hybrid** |
|---|---|---|---|
| Objem/sval/týden | 15–20 sérií | minimum | **8–12 sérií** |
| Split | PPL, high freq | doplněk | **upper/lower nebo full body** |
| Intenzita | často failure | 3–4 RIR | **2–3 RIR, ne failure** |
| Cardio | minimum | primární | **běh je primární, gym doplněk** |

**Klíčový mentální posun:** v BB je vynechaná série ztráta.
V hybridu je recovery součást tréninku. Snížit zátěž o 10 % po náročném
long runu není selhání.

## Síla vs. hypertrofie pro běžce

**Pro běžce je silový trénink prokazatelně užitečnější než hypertrofický:**
- Běh vyžaduje rychlou produkci síly, ne objem svalu
- Heavy strength training zlepšuje **running economy**
  (neuromuskulární efektivita — více síly bez většího svalu)

**Kompromis pro tento profil** (BB cíle + deficit + udržení hmoty):
- Hlavní pohyby: **3–6 opakování** (síla)
- Doplňkové: 10–15 opakování (udržení objemu)
- Lýtka: 12–20 (reagují lépe na vyšší opakování)

**Nejít pod 3 opakování** — při deficitu a rostoucím objemu běhu zvyšuje
riziko zranění a CNS únavu bez benefitu.

## Aktuální split
- Původní: St + So upper, Ne lower
- Doporučený hybrid split níže

## Doporučený hybrid split

```
Po  Easy run
Út  Upper A (push)
St  Easy run + Lower A (odpoledne)
Čt  Volno / chůze
Pá  Upper B (pull)
So  Easy run nebo volno
Ne  Long run ráno + Lower B odpoledne
```

### Upper A (push)
| Cvik | Série × opakování |
|---|---|
| Bench press | 3 × 4–6 |
| Overhead press | 3 × 5–7 |
| Incline DB press | 2 × 8–10 |
| Triceps | 2 × 10–12 |
| Core | — |

### Upper B (pull)
| Cvik | Série × opakování |
|---|---|
| Weighted pull-up nebo row | 3 × 4–6 |
| Cable / chest-supported row | 3 × 6–8 |
| Face pull | 2 × 15 |
| Biceps | 2 × 10–12 |
| Core | — |

### Lower A (síla, složené)
| Cvik | Série × opakování |
|---|---|
| Squat nebo Bulgarian split squat | 3 × 4–6 |
| RDL | 3 × 5–7 |
| Pallof press | 2 × 10/strana |
| Lýtka | 2 × 15–20 |

### Lower B (doplňkový, lehčí)
| Cvik | Série × opakování |
|---|---|
| Leg press | 3 × 8–10 |
| Leg curl | 3 × 8–10 |
| Single leg glute bridge | 2 × 10–12 |
| Dragon flag | 2 |
| Leg raise | 2 |

**Pokud je long run výjimečně náročný, Lower B úplně vynechat bez výčitek.**

## Frekvence nohou

**1× týdně stačí**, ale 2× s nižším objemem je lepší:
- Svalová proteosyntéza trvá 48–72 h po tréninku
- Při 1×/týden je 4–5 dní bez stimulu
- Celkový týdenní objem stejný, lépe rozložený

**Cíl: 10–14 sérií na nohy týdně, rozdělených do 2 dnů.**

## Core

| Cvik | Série | Proč |
|---|---|---|
| Dragon flag | 2 | anti-extenze páteře, nejlepší pro běh |
| Leg raise | 2 | flexory kyčle, spodní břicho |
| **Pallof press** | 2 × 10/strana | anti-rotace, přímo relevantní pro běh |

**❌ Weighted side bend — vyřadit.**
Zatěžuje QL a boční flexory v rozsahu, který při běhu nevyužiješ.
Navíc hypertrofie bočních svalů trupu vizuálně rozšiřuje pas.

**Alternativa:** single leg glute bridge. Slabé hýždě = kolébání pánve
při běhu = horší ekonomika + vyšší riziko zranění.

## Timing vs. běh

**Pravidla:**
1. **Běh ráno → gym odpoledne** (stacking). Nikdy naopak.
2. **NIKDY gym-nohy den před long runem**
3. **NIKDY gym-nohy den po long runu**
4. Stacking (tvrdý den + tvrdý den) + čistý rest day
   > střídání run/gym/run/gym nonstop
5. Ideál pro lower: hned po kvalitní session (úterý odpoledne) nebo ve středu

## Progrese při rostoucím objemu běhu

| Fáze | Lower day |
|---|---|
| Base (teď) | plný objem, 4–5 cviků |
| Build (55+ km) | ubrat série, ne cviky |
| Peak (65–70 km) | jen squat/BSS + RDL, 2–3 série, udržovací |

## Domácí leg day (činky do 17,5 kg)

| Cvik | Série × opakování | Pozn. |
|---|---|---|
| Bulgarian split squat | 3 × 5–6/noha | 3s excentrika |
| RDL | 3 × 6–8 | 3–4s dolů, pauza dole |
| Single leg glute bridge | 3 × 10–12/noha | pomalé |
| Lýtka na schodě | 3 × 15–20 | 3s excentrika |
| Core | dragon flag, leg raise, dead bug | |

Chybí těžký squat, ale BSS s pomalou excentrikou to zastoupí.

## Na cestách (bez gymu)
2× týdně 20 min bodyweight: dřepy, výpady, kliky, plank.
Udržovací, ne progresivní.
